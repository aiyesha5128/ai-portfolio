# 🏥 AI Medical Coding Assistant (ICD-10 + CPT)

## 📌 Overview
This project extracts ICD-10 and CPT codes from clinical notes using keyword-based logic.

## 🚀 Features (Phase 1)

- Input: Clinical note
- Output:
  - ICD-10 code
  - CPT code
  - Explanation for each code
- Simple keyword matching
